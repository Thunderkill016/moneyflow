# Webflow Design category inventory

**Accessed:** 2026-08-04
**Status:** reference inventory; the synthesis and current MoneyFlow authorities decide applicability

This inventory records the topic coverage found in the current public snapshot of https://webflow.com/blog/category/design. The category is live and exposes a “Show more” boundary, so this is a dated snapshot rather than a claim of permanent historical completeness.

## Process and UX foundations

- How to learn web design in 9 steps (+ best practices)
- The user-centered design process: 4 key principles
- A complete guide to user journey mapping and optimization
- How to create websites with great UX designs: Principles and examples
- Visual user flows: A guide to mapping user journeys
- UX wireframing and modern web-design-process articles
- Website prototyping tools
- Conceptual design

**MoneyFlow use:** active process evidence for user jobs, journeys, flows, content, wireframes, prototypes and iterative evaluation.

## Homepage, hero and conversion structure

- Homepage design guidance and examples
- Hero image best practices
- Simple web design tips for beginners
- Contact form conversion guidance
- Testimonials and social-proof guidance
- Business, healthcare and other industry homepage examples

**MoneyFlow use:** adapt for clear value proposition, one primary CTA, real product proof, readable forms and honest evidence. Do not copy industry layouts or invent testimonials.

## Composition and visual fundamentals

- Composition for web design
- Visual hierarchy, balance, scale, contrast, whitespace, proximity and repetition
- Modern UI examples
- Minimalist, brutalist, neumorphic and other visual-style articles
- Color palette inspiration and color theory
- Typography, font selection and font-pairing articles

**MoneyFlow use:** active evidence for hierarchy and legibility; style/trend lists remain option generators rather than authority.

## Brand and design systems

- Brand design and brand-identity guidance
- Branding inspiration sites
- Design systems: definition, examples and creation
- From components to systems that scale
- Brand consistency and shared sources of truth

**MoneyFlow use:** active evidence for governance, semantic tokens, stable component purpose, variants, documentation and maintenance. Exact external identities are not copied.

## Accessibility, responsive design and compatibility

- ARIA and accessibility guidance
- Responsive/mobile design guidance
- Cross-browser testing
- Dark mode design
- Legibility and performance guidance

**MoneyFlow use:** active release constraints. Native semantics, keyboard access, visible focus, contrast, target sizes, text zoom, reduced motion and Chromium/WebKit coverage remain required. Public Light-only behavior is an explicit MoneyFlow owner decision.

## Motion and advanced presentation

- Scroll animation examples
- Website animation examples
- Carousels
- Parallax scrolling
- Scrollytelling and interaction inspiration

**MoneyFlow use:** adapt cautiously. Motion must explain, provide feedback or preserve continuity. Parallax and heavy scrollytelling are rejected for authenticated finance tasks; critical content cannot depend on an auto-advancing carousel.

## Navigation and information access

- Mega menu examples
- Creative website menu ideas
- Blog layouts and content navigation

**MoneyFlow use:** principles of clear structure and predictable navigation apply. Mega menus are rejected for the current small public sitemap.

**MoneyFlow use:** reference only. Tool articles do not authorize dependencies, workflow replacement or platform migration.

**MoneyFlow use:** reference only for communicating work and evidence; not a product acceptance source.
