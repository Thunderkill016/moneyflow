# Industry synthesis — personal finance web (for agents)

**Date:** 2026-07-15  
**Use:** implement with skill `moneyflow-web`; do not expand scope beyond G5.

## Product archetypes

| Archetype | Pattern to steal | MoneyFlow |
|-----------|------------------|-----------|
| Tracker (Money Lover) | Fast add, multi-wallet | Core |
| Envelope (YNAB/Actual) | Intentional budgets | Lite budgets only |
| Dashboard (Monarch) | One overview | Insights |
| Attention (Copilot) | “Cần chú ý” | Attention strip |
| Ledger (Firefly) | Transfer ≠ expense | Double-entry lite |

## MVP must-haves (industry consensus)

Auth · wallets · expense/income/transfer · categories · dashboard KPIs · category budget · period report · **CSV export** · soft delete

## Explicit non-MVP

Bank open banking · AI advisor · family · OCR · full envelope onboarding · AGPL code copy

## Daily loop quality bar

1. Time to first expense &lt; 60s  
2. Add expense &lt; 10s  
3. Transfer never in chi totals  
4. One primary empty-state CTA  
5. Export one click from settings/reports  

## UX

Trust · clarity · calm Vietnamese · progressive disclosure · money not color-only
