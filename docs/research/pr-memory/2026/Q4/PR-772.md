  - All 5 remaining update RPCs (`upsert_recurring_commitment`, `upsert_savings_goal`, `update_financial_account`, `upsert_monthly_budget`, `upsert_recurring_income_template`) were last-write-wins — two tabs/devices editing the same record silently overwrote each other.   - 5 new pgTAP suites (stale → fail closed; matching → pass; null → legacy), `schema_and_rls` signature checks updated, new contract tests in `src/lib/optimistic-concurrency-batch-contract.test.ts`.
