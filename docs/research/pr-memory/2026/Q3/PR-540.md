## Browser regression found by the patch

The first full browser smoke after the dependency patch passed 134/136 tests. Both failures were the same Share Target path at desktop/mobile widths: `/capture/share` remained on the Vietnamese loading state instead of ingesting the staged payload and redirecting to `/inbox`.

`CaptureSharePage` schedules its one-shot ingestion in `requestAnimationFrame`. The prior effect cleanup cancelled that scheduled frame during development effect replay, which could strand the route before ingestion began. The fix keeps the queued frame alive across the replay and leaves `ranRef` as the one-shot guard inside the callback, so whichever frame actually starts first consumes the operation and duplicate callbacks exit. The existing Playwright assertion still requires the route to reach `/inbox`; no assertion was weakened.

## Live Supabase advisor reconciliation

Read-only provider evidence was refreshed after dependency work. Security Advisor continues to report authenticated-callable `SECURITY DEFINER` warnings across ledger/planning/reconciliation/import/archive RPC surfaces and separately reports leaked-password protection disabled.

Live catalog reconciliation of the warned function set found no `anon` or `PUBLIC` execute grant, retained intended `authenticated` execute, `postgres` ownership, empty `search_path`, and an `auth.uid()` reference in every warned body. The identity-parameter case `reconciliation_snapshot_for_user(p_user_id, ...)` explicitly rejects a caller when `p_user_id is distinct from auth.uid()`. Representative mutation functions inspected live derive tenant identity from `auth.uid()` and bind effects to that identity. Repository `cross_tenant_rpc.test.sql` and `browser_role_privileges.test.sql` provide additional ownership/role regression coverage.

This narrows the lint class to intentional privileged authenticated RPC surfaces rather than accidental anonymous/public exposure, but it is not a blanket waiver. Each surface still needs evidence-based disposition before suppression or privilege change. No `SECURITY DEFINER` function was converted, moved or revoked here.
