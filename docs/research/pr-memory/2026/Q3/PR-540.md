3. because the Supabase organization is on Free and has no automatic backups/PITR, create logical schema and data dumps and keep them private/off-repository;
4. run `supabase db push --dry-run` and require exactly the expected 15 pending migrations in timestamp order; dry-run previews the list but does not validate SQL;
