## The delivered candidate was a no-op

`@theme inline` sat in `src/app/legacy.css`, which has no `@import "tailwindcss"`,
so Tailwind never processed it. Measured against a clean production bundle: not
one semantic utility generated, `--color-background` absent from the output, and
the ownership inventory byte-identical to #337 (`ownedUnconditional: 115`,
`staleAllowances: 0`).

Moved into `globals.css`, beside the aliases it references. Verified generated:
`bg-background`, `bg-card`, `bg-muted`, `bg-primary`, `bg-destructive`,
`bg-secondary`, `text-foreground`, `text-muted-foreground`,
`text-primary-foreground`, `text-destructive`, `border-border`, `border-input`,
`border-ring`, `ring-ring`, plus the chart and sidebar roles.

## Ownership delta

Baseline **346 → 319**. All 27 removals verified against the bundle before the
baseline was touched: 23 gained an unconditional owner, 4 are variant prefixes
whose guarded utility now exists (`dark`, `aria-expanded`, `placeholder`, and

`confirmedUnowned` 227 → 203, `ownedUnconditional` 115 → 134.

## `muted`

`--color-muted: var(--mf-surface-muted)` — not `var(--muted)`, a legacy alias for
a *text* colour that would paint mid-grey text as a background, and not
`var(--secondary)`, which shares the value today but is a distinct role.

## The bridge alone would have regressed contrast

`button { color: inherit }` and `a { color: inherit }` were unlayered, so they
outranked every Tailwind `text-*` utility. Measured on the real primary button:

| | light | dark |
|---|---|---|
| bridge alone | 2.99:1 | 2.05:1 |
| bridge + layered resets | 5.93:1 | 6.48:1 |

Ratios computed from measured rgb. Cause confirmed through
`CSS.getMatchedStylesForNode`: `@layer utilities` losing to an unlayered rule.

Before either change those elements were on unstyled defaults — transparent
backgrounds, black borders, identical in light and dark. Dark mode genuinely did
not resolve on them.

## Limitations

`bg-card`, `bg-muted` and `bg-destructive` are proven by generated declaration,
not rendered appearance — they need interaction or an opacity modifier. Toast,
Sheet and Dialog were not opened; Card, Accordion, RadioGroup and CheckboxField
have no importers. No WCAG claim beyond the two measured button states. The
layered-reset change affects cascade precedence for every button and link and is
the main thing to scrutinise.
