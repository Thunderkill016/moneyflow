- Remaining: authenticated grant list + revoke round-trip needs a real Supabase session — verify on production after deploy (list a real `mcp-inspector` grant, revoke it, confirm the MCP token dies).

## Boundaries

- Read/revoke only — no grant detail editing, no session list (Supabase API exposes grant-level revoke only).
- Revocation is immediate and kills the client's sessions; the dialog states this before confirm.
- Demo mode never reaches `listGrants` — the server page branches on `viewer.isDemo` first.

## Evidence limits

- `listGrants`/`revokeGrant` behavior asserted from the installed `@supabase/auth-js` type surface and the earlier live OAuth smoke; the authenticated round-trip itself was not exercised locally (no session in demo mode).
