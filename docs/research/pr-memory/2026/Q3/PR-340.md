## Why the confirmation rule is its own module

`actions.ts` cannot be imported by a unit test (`next/cache`, `next/headers`), so
the match rule lives in `lib/auth-password-confirmation.ts`. Without that,
"a mismatch never reaches Supabase" would be a claim rather than an assertion.
Six tests cover it, including the parse → guard → `signUp` ordering.

## Evaluator finding worth recording

The reveal toggle was 40px tall and failed the repository's own 44×44
minimum-target-size audit on login and register at 320px. The gate caught it, not
the author. Raised to 44×44 and re-verified.

## Limitations

Dropdown evidence comes from the authenticated harness and its loopback double,
not a hosted Supabase project. Viewports are emulated — not physical-device
acceptance. `auth-captcha` e2e cannot run locally without a Turnstile key.
