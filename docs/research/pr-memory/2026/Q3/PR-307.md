## Financial lifecycle boundary

Current MoneyFlow behavior keeps archived account balances/history but excludes archived accounts from active-account totals and new-transaction choices. Phase 6 preserves that behavior and makes the consequence explicit in the UI.

A rule requiring a zero balance, a balancing transfer or an automatic account-closing transaction would change financial lifecycle semantics. That work requires a separate owner-approved Class 3 packet and affected domain/database/browser evidence; it is not hidden inside this presentation migration.
