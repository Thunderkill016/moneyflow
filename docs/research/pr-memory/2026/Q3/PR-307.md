## Financial lifecycle boundary

Current MoneyFlow behavior keeps archived account balances/history but excludes archived accounts from active totals and new-transaction choices. Phase 6 preserves that behavior and makes the consequence explicit.

A rule requiring zero balance, a balancing transfer or an automatic account-closing transaction would change financial lifecycle semantics. It requires a separate owner-approved Class 3 packet and affected domain/database/browser evidence.
