# PR #713 — Numeric spent/limit figures on budget attention chips

- Date: 2026-09-25
- Change class: Class 2 (user-interface surface; no schema, no migration —
  CI selects browser smoke + responsive audit lanes)
- Affected capability or project boundary: `buildAttentionItems` budget
  branch (`src/lib/attention.ts`) — the only place attention-chip labels
  are composed; `/budgets` and `budgetStatusLabel` semantics unchanged.
- Status impact: budget chips now carry ledger-derived figures instead of
  qualitative-only text — near shows spent/limit, over shows overshoot plus
  spent/limit context. Exception-only behavior, link target, tones and the
  four-item cap are unchanged.
- Changed:
  - near → `{category}: {spent}/{limit}` in compact VND
    (e.g. `Ăn uống: 4,2 tr/5 tr`); the bare "Gần hạn mức" wording is
    replaced because the figures are the near signal.
  - over → `{category}: Đã vượt {overshoot} ({spent}/{limit})`; keeps
    `budgetStatusLabel(budget, chipMoney)` for the overshoot and appends
    context in parentheses.
  - Every figure goes through `chipMoney` (compact VND ≥ 1 tr, exact ₫
    below) so single-line pills do not crowd; exact đồng remains on
    `/budgets`.
  - `attention.test.ts` pins exact labels for both states (84% and 124%
    fixtures); the compact-VND surface contract keeps passing because the
    over branch still calls `budgetStatusLabel(budget, chipMoney)`.
- Verified:
  - `typecheck` clean; `npm test` 1858/1858; `lint` 0 errors (one
    pre-existing unrelated warning in `quick-add-defaults.test.ts`);
    `check:knowledge`, `check:architecture`, `test:ci-policy` 191/191;
    `NEXT_PUBLIC_APP_MODE=demo npm run build` 52 routes.
  - Browser (demo, :3100, temporary demo-seed tweak reverted after):
    chips render `Ăn uống: 3,4 tr/4 tr` and
    `Mua sắm: Đã vượt 100.000 ₫ (2,1 tr/2 tr)` — no horizontal overflow,
    zero console errors.
- Remaining: CI green on the exact head is required; merge is the owner's
  call. Multi-month trend stays on `/reports`; net-worth/investment stays
  a pinned non-goal.
- Production/provider evidence: none — not deployed, no schema.
- Superseded issue, roadmap or claim: closes the "budget chips are
  qualitative only" gap called out in the post-#712 dashboard comparison;
  G5 (hydration/perf) remains measurement-gated.
- Lifecycle impact: chip labels are now figure-bearing — future budget
  states (e.g. watch) that join the strip must keep the same
  spent/limit discipline and compact formatting.
