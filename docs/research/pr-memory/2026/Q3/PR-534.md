## Rationale

Next.js lazy-loading guidance supports deferring Client Components and libraries that are not needed for the initial render. The existing capture/transfer components were already `next/dynamic`, but mounting them while closed still made them part of the initial dashboard render path. Conditional mounting preserves the same dialog behavior while deferring the dynamic chunk until the user opens it.

The landing story image sits below the hero and was marked `priority`, which explicitly preloads it. Removing `priority` restores normal lazy image loading so the below-fold screenshot does not compete with first-screen resources.
