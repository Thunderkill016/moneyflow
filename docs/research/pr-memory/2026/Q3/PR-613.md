## Boundaries

- Stateless is required on serverless — no session resumability; SSE transport not mounted (Streamable HTTP only, per current spec).
- Tools expose exactly the capability registry — no MCP-only fields, no second contract; a capability addition becomes a tool automatically.
- Viewer isolation comes from the P2a auth seam (RLS under the token), not from tool args — the per-request server closes over the verified viewer id.
- `authorization_servers` points at Supabase's issuer URL; the OAuth 2.1 server itself is enabled in P2c — metadata is correct before and after that enablement.
