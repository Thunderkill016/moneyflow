- **Status impact:** none

## Scope

Detach the current Tổng quan component from the legacy global `.dashboard` class. The route-owned `.insights-dashboard` CSS already defines desktop and phone padding; the legacy class re-applies `--mobile-content-end`, which still includes clearance for a floating action button removed by the current shell.

## Root cause

`MoneyFlowDashboard` rendered `className="dashboard insights-dashboard"`. On phone, `ui-refresh.css` applies important bottom padding through `.dashboard`, while `app-shell.module.css` separately reserves the fixed navigation. The two clearances stack and leave excessive blank space after the final dashboard content.

## Change

- render only the current route-owned `insights-dashboard` class;
- add a static regression proving the legacy class cannot return;
- confirm route padding and shell navigation reserve remain separately owned.
