## Transport decision, recorded because it changed

The first implementation called Supabase from the browser, on the reasoning that
the RPCs were designed for that path. `check:architecture` rejected it:
`src/components` may not import Supabase and no hook in this codebase does
either. The repository contract won, and the feature moved to server actions.

The cost is a transport ceiling, stated rather than hidden: server action
requests cap at 1 MB by default (~1,300 transactions at ~786 B each), raised to
4 MB, with the platform's ~4.5 MB serverless request cap as the real ceiling
(~5,000 transactions). The surface refuses a larger archive before upload. R8's
64 MiB parser bound is unchanged — this is transport, not parsing.

## Deployment-order safety

Both archive migrations are merged but unapplied, so this UI can be live before
the capability exists. `PGRST202` is classified as a capability gap and shown as
an honest "not ready on the server" state — no crash, no false promise, no retry
loop — and the surface becomes usable with no code change once the migrations
are applied.
