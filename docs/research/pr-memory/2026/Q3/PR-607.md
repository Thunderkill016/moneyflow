## Boundaries

- Brand is type-level only: runtime values are unchanged JSON-safe integers and all golden outputs are byte-identical; optional `splits` stays omitted when absent.
- Scope is deliberately the capability contract, not the whole codebase — `minor()` is the single validated conversion point where loader `number`s become branded.
- Zod `.int()` is what emits the ±2^53-1 JSON Schema bounds; a bare `.brand()` over `.number()` would degrade the manifest to `type: "number"`.
- No new data path, mutation owner, transport, migration or runtime dependency.
