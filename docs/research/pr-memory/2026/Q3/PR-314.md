## Evidence boundary

The implementation follows current official GitHub CLI and Actions interfaces for force cancellation, manual workflow dispatch by ref, exact-SHA run listing and exit-status watching. Repository tooling cannot repair a GitHub service outage or guarantee runner capacity; a waiting-state timestamp by itself is not proof of a zombie run.

Manual CI recovery is not security-analysis substitution. A successful `ci.yml` replacement proves only that workflow. Required CodeQL still needs a real pull-request analysis/result for the candidate, and secret-history evidence remains owned by its protected workflow. A feature-branch `workflow_dispatch` of CodeQL must not be assumed equivalent to PR-scoped code-scanning evidence without a dedicated, verified governance contract for the uploaded `ref`/`sha`.
