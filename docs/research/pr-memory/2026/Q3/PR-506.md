# PR #506 — make research navigable without creating a second source of truth

- Date: 2026-08-27
- Change class: Class 0 — documentation/navigation only. No runtime, schema, migration, RPC, RLS, provider, deployment or financial-semantic change.
- Affected capability or project boundary: repository research navigation and the reusable shape of future bounded research records.
- Status impact: none. `CURRENT_PROJECT_MEMORY.md`, runtime capability and release readiness are unchanged.
- Lifecycle impact: none. This PR does not select, complete, promote or authorize a product/governance slice.
- Repository evidence read first: `AGENTS.md`, root `README.md`, `docs/research/CURRENT_PROJECT_MEMORY.md`, `docs/plans/PLAN_AUTHORITY.json`, `docs/plans/active/README.md`, the existing `docs/research/README.md`, `01_RESEARCH_PLAN.md`, `MONEYFLOW_REFERENCE_REPO_ATLAS_2026.md`, `REPOSITORY_REFERENCE_MAP.md` and `docs/context/README.md`.
- Finding: MoneyFlow already has a substantial research repository under `docs/research`; creating a separate research repo would duplicate current-vs-historical routing and create another place that could be mistaken for execution or product authority.
- Changed: `docs/research/README.md` is reorganized as a research hub that routes current truth, execution authority, product/market evidence, domain/architecture references, UI/UX evidence and PR provenance without promoting research into roadmap authority.
- Added: `docs/research/RESEARCH_RECORD_TEMPLATE.md` for reusable bounded studies. It requires one decision question, current MoneyFlow reality, 2–4 focused sources by default, applicability limits, fact/inference separation, confidence, alternatives, an `Adopt | Adapt | Reject | Defer | Needs owner decision` posture, verification needs and invalidation conditions.
- External method evidence was deliberately narrow: Diátaxis (`https://diataxis.fr/`) supports separating documentation by reader need rather than mixing every purpose into one document; Microsoft Azure Well-Architected ADR guidance (`https://learn.microsoft.com/en-us/azure/well-architected/architect-role/architecture-decision-record`) supports concise decision context, alternatives, consequences, status and a single documentation repository. These sources inform document shape only and do not override MoneyFlow policy.
- The template intentionally does not introduce a separate research backlog, decision queue or new authority graph. Current work remains owned by `docs/plans/active/README.md` after plan authority resolves.
- The branch was created from current `main`; comparison before opening the PR showed it ahead by two documentation commits and behind by zero. After this record, the PR remains documentation-only.
- Verification available in this session: repository/branch comparison and GitHub file-level review. Local repository commands such as `npm run plan:resolve`, `npm run check:knowledge` and `npm run test:ci-policy` could not be executed because the connected GitHub workspace exposes repository files/actions but no checked-out runtime. Required PR CI remains the machine evidence.
- Production/provider evidence: none required and none used. No provider write, production read, deployment or production-data access.
- Snapshot update: none; current implementation/trust truth did not change.
- Superseded issue, roadmap or claim: none. This PR strengthens navigation for existing research and does not supersede product direction.
