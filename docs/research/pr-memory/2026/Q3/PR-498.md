- The licence decision, delegated by the owner and reasoned rather than picked: a public repository with no licence defaults to all rights reserved, which is almost always an omission and leaves a reader unable to tell whether it was intended. The two open-source products in this category chose opposite ways — Firefly III took AGPLv3, Actual Budget took MIT. AGPL-3.0 matches Firefly III, the closest structural analogue. The reasoning is specific: MIT would let a hosted competitor built from this code close its source, and a solo product with no company, no marketing and no moat beyond the work itself cannot absorb that. The pattern is documented — Elasticsearch, Redis and MongoDB each watched a permissive licence hand their work to a hyperscaler and each relicensed in response.
- The trade-off, stated rather than buried: copyleft makes the code unattractive for commercial reuse and acquirers dislike it, so if selling the product ever becomes a goal this is the decision to revisit deliberately. Nothing is foreclosed either way — as sole copyright holder the owner can dual-license or relicense at any time, because AGPL constrains others and never the holder.

- `/api/health` is deliberately shallow, and the shallowness is the design: it answers whether the deployment serves requests, not whether everything works. A test asserts it contains no database call. It is `force-dynamic` with `no-store`, because a cached health check reports the health of whatever was true when it was cached.
