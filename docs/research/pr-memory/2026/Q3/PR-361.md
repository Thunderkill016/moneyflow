## Evaluation model

The generator implements against the real MoneyFlow React/CSS application and captures
phone plus desktop evidence. A different evaluator session/agent inspects that evidence,
exercises at least one meaningful browser interaction, records scored design criteria and
hard gates, and returns pass/refine/pivot. `design:check` rejects below-threshold scores,
missing gates/evidence, unresolved blocking findings, or identical generator/evaluator
identities.
