## Environment contract

The default cloud environment uses Node.js 20, `npm ci`, and preloads the Playwright Chromium/WebKit binaries during the setup phase. A maintenance script reconciles dependencies when a cached Codex container resumes on a newer commit.

Normal cloud work uses demo-mode public configuration only. No production credential is stored in the repository or required by the default environment.

Agent internet is intended to stay restricted to common dependency infrastructure plus a small set of trusted product/documentation domains, with read-only HTTP methods by default.

## Verification boundary

Static, unit, build and browser checks are available according to `AGENTS.md`. The Supabase database/RLS gate remains boundary-specific and must not be claimed in Codex Cloud unless the active runtime actually provides the required local container runtime. GitHub CI/Linux remains the authority for that gate when Cloud cannot provide it.

## Provider boundary

This environment is for implementation, analysis and reviewable diffs/PRs. It is not a production administration environment. Provider or production writes still require explicit owner approval, minimum-scoped credentials and the existing Class 3/work-packet process.
