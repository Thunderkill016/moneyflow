# PR #719 — Two-up secondary actions on phones instead of full-width stack

- Date: 2026-09-25
- Change class: bounded UI/CSS (Class 2-presentational). No JS/TSX,
  no schema, no server action.
- Affected capability or project boundary: phone-width layout density
  of secondary action groups across 8 CSS modules; desktop (≥761px)
  behavior unchanged.
- Superseded issue, roadmap or claim: closes the "mobile secondary
  actions stack one full-width row each" finding from the whole-app
  design comparison (2026-09-25). Leftovers logged: desktop `/capture`
  narrow column, whole-app dark-mode visual sweep, `/reports`
  96×16px "Tùy chọn xuất" inline-link tap target (P3, pre-existing).
- Context: at ≤760px shared `SecondaryHeader` actions and per-page
  action groups rendered `flex: 1 1 180px` or `1fr` — on a 390px phone
  one ~50px full-width row per button (~250px before content on
  /inbox).
- Changed (CSS only): at the existing mobile breakpoints every
  `.actions`-style group keeps `display:flex; flex-wrap:wrap` with
  children `flex: 1 1 45%; min-width: min-content` — short labels go
  two-up, a long nowrap label exceeds 45% and takes a full row instead
  of overflowing (director finding: "Xem lại ghi 1 giao dịch" ~167px
  vs ~144px cell). Single-column at ≤340px via `display:grid; 1fr`.
  Files: `secondary-layout` (`.actions`/`.sectionAction`),
  `transactions-workspace` (`.headingActions`), `planning-workspace`,
  `rules-page` (incl. `.dialogFooter`), `imports-page`,
  `import-preview-page`, `direct-csv-import-page`, `inbox-bulk-bar`
  (`.buttons` only — `.actions` there is a radio fieldset and stays
  stacked).
- Round-2 review fixes (director, 2× P2, both resolved before merge
  request):
  1. Long nowrap button labels could overflow a fixed half-row →
     `min-width: min-content` auto-promotes them to a full row.
  2. `.summary` 2-up at ≤480px could break `MoneyValue` (nowrap,
     ~154px at 17px) → reverted; summary stays 1-col on phones.
     Money never wraps.
- Verification:
  - Browser sweep 9 routes × {390,360,320,1440}px: 0 console errors,
    0 horizontal scroll, per-element clip check (scrollWidth ≤
    clientWidth on every a/button), targets stay 44px.
  - Interactions: "Chia khoản chi" dialog open/close at 390px, kind
    chip aria-pressed filter, inbox bulk bar.
  - Independent design evaluator (round 1, grid variant): PASS
    (8/7/8/9, all gates, `design:check` pass); round-2 flex revision
    re-verified by the same sweep after addressing both P2s.
  - Gates: lint, typecheck, build 52 routes, css-ownership, dead-css,
    code-css-ownership (0 new/0 stale, 211 baseline), ci-policy
    191/191, knowledge. Test suite unchanged (CSS-only).
- Follow-ups (not in scope): /reports inline-link tap target; desktop
  /capture column width; whole-app dark-mode visual sweep.
