# PR #678 — Payee spend breakdown on /reports + payee category suggestion chip

- Date: 2026-09-22
- Change class: Class 1–2 (domain helpers + bounded presentation; no migration, schema or RPC change)
- Affected capability or project boundary: `src/lib/reports.ts` (additive `FinancialReport.payees`), `src/lib/report-drilldown.ts` (`query` slice, `requiresQuery` guard, `reportPayeeDrilldownHref`), `src/components/reports-page.tsx` (`report-payees` section), `src/lib/quick-add-defaults.ts` (`derivePayeeCategorySuggestion`), `src/components/add-transaction-dialog.tsx` (suggestion chip + `applyPayeeChange`), `src/server/capabilities/reports-financial.ts` (declared-field projection).

The dialog renders it as a labelled `Gợi ý · <category>` chip applied only through `chooseCategory`; the payee field's change handler is a dedicated `applyPayeeChange` that cannot touch category state (pinned by a contract test). `reports.financial` output now projects declared fields instead of `...report` so `payees` stays page-facing.
