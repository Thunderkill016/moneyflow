- Affected capability or project boundary: release-readiness preparation for the P1 gates. Adds `docs/compliance/P1_GATE_PREPARATION.md`, a data inventory and provider read-back checklist derived from current migrations and runtime code.

- Findings surfaced while gathering evidence, recorded rather than smoothed over. First, RRB-05 is not merely open: `src/components/privacy-policy-page.tsx` already publishes `support@moneyflow.app` and the live policy makes a commitment on it, while nobody has verified the operator controls that address — if not, the policy must change before beta. Third, `supabase/tests/database/tenant_isolation_and_deletion.test.sql` enumerates tables by hand rather than deriving them from the schema, so it cannot notice a new tenant table; five tables the purge does delete are absent from it. None of these is a live data leak; the second and third are claims that no longer match their code.
