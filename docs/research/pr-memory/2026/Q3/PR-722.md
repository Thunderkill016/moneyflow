- Date: 2026-09-25
- Change class: feature slice — new deterministic domain helper, one

  `/budgets`, demo-fixture extension. Owner granted autonomous merge

- Affected capability or project boundary: `/budgets` workspace read

- Superseded issue, roadmap or claim: surface audit gap — budgets setup

- Status impact: categories missing a limit for the viewed month now get
  a suggested value with its evidence window disclosed; suggestion only
  materializes on explicit user action (one click or prefilled dialog).
- Design basis:
  - `budget_progress` joins only categories that already have a budget
    row, so the evidence read must be `transaction_feed` — the view
    structurally cannot see the spend a suggestion exists to find.
  - Average divides the window total by the whole window (quiet months
    count) because a monthly limit must cover quiet months; partial
    evidence is disclosed as `monthsWithData`, never hidden inside the
    average.
  - Splits attribute per `categoryId` — the same per-entry accounting
    `spent_minor` uses — so a suggestion cannot disagree with the
    eventual "Đã chi" figure.
  - `BUDGET_SUGGESTION_MIN_AMOUNT` 10.000 ₫ floor: a sub-floor average
    is noise, not signal.
