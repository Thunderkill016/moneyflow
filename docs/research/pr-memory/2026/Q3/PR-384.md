## Evidence boundary

The process-level command guard is defense in depth. It constrains ordinary inherited `git`/`gh` execution paths but is not represented as an OS sandbox or hostile-process boundary. A process deliberately executing an absolute binary path can bypass the `PATH` wrapper; Codex sandboxing, repository protection and owner-scoped credential controls remain independent safeguards.
