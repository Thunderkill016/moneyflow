## Financial-model boundary

MoneyFlow keeps its current tracking/category-budget model:

- a Budget is a monthly category limit compared with recorded expense rows;
- a Commitment is an expected obligation until explicit payment creates a real expense;
- a recurring income template is an expected inflow until explicit receipt creates a real income row;
- Goal allocation is a planning earmark and does not transfer, lock or remove money from an account balance.

A true envelope model, assigned/available balances, rollover, automatic schedule matching, account-backed Goal funding, contribution history or new safe-to-spend guidance changes product and financial semantics. Each requires a separate owner-approved Class 3 packet and affected domain/database/browser evidence.
