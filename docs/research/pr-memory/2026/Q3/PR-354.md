## Design decision

The doctor reuses `scripts/classify-ci-changes.mjs` as the verification-policy authority instead of creating a second risk classifier. It inspects repository state, changed files, locally available tool capabilities and environment-variable presence, then emits the local gate plan selected from the existing policy. Secret values are never printed.

Provider-required checks are reported separately from local commands so a locally green run cannot be mistaken for complete PR evidence. Existing `AGENTS.md`, risk-proportional delivery policy, the protected-branch ruleset and CI remain authoritative.

The doctor is executable tooling, not a parallel management framework.
