## Design decision

The doctor reuses `scripts/classify-ci-changes.mjs` as the verification-policy authority instead of creating a second risk classifier. It inspects repository state, changed files, locally available tool capabilities and environment-variable presence, then emits the gate plan selected from the existing policy. Secret values are never printed.

The doctor is executable tooling, not a parallel management framework. Existing `AGENTS.md`, risk-proportional delivery policy and CI remain authoritative.
