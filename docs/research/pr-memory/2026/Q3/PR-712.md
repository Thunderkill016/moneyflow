## Decisions

- Group key is `occurredOn`, not the display string — one calendar day can
  never split into two groups even if labels ever diverge.
- Header reuses the ledger's own `relativeDate` label; no new date format
  invented. Rows keep icon/detail/amount only — the product deliberately
  displays day granularity, not HH:mm.
- No data/loader changes; presentation-only.
