# PR #721 — Reports: income categories, period navigation, savings rate

- Date: 2026-09-25
- Change class: Class 2 — deterministic report-domain fields plus
  presentation on an existing surface. No schema, auth, RLS or money-write
  changes. Owner granted autonomous merge authority this session.
- Affected capability or project boundary: `/reports` read model
  (`buildFinancialReport` in `src/lib/reports.ts`), its drilldown helper
  module, and the reports workspace type consumed by `reports.financial`
  capability (`todayIso` added to `ReportsWorkspace`).
- Superseded issue, roadmap or claim: surface-audit backlog item "Reports
  slice: income-by-category + prev/next period nav + savings rate" — the
  three verified gaps against comparable products.
- Status impact: `/reports` now breaks down income by category with
  six-month strips, offers one-tap previous/next period navigation, and
  shows the kept share of income. No production/provider writes involved;
  effect is live at deploy.
- Changed:
  - `incomeCategories` on `FinancialReport`: income grouped by category
    with the same split-distribution and six-month trend-strip rules as
    `categories`; shares divide by period income, so a partially tagged
    month sums under 100% honestly.
  - `savingsRatePercent`: `net / income` rounded; `null` when income is
    zero (a percentage needs a denominator); negative when spending
    exceeds income — never clamped to zero.
  - `adjacentReportRanges(range, today)`: presets step by calendar unit
    (whole previous month/year, ISO week); custom windows shift by their
    own span — the same equal-length rule the comparison totals use.
    `next` is `null` when the following window is entirely future and
    clamps at `today` when it overlaps.
  - `reportIncomeCategoryDrilldownHref`: `kind=income`, refuses blank
    names so a category link cannot open the whole ledger as one slice.
  - `ReportsWorkspace.todayIso`: server-stamped clock used to resolve
    the range; chevron clamping agrees with it across a midnight
    boundary (a browser clock is not consulted).
  - UI: chevrons flanking the period pill reuse `.periodLink` (44px
    targets); navigation always emits `period=custom&from&to` — a past
    calendar month is not the `tháng này` preset and a preset URL would
    mislabel the window. New "Thu theo danh mục" section mirrors "Chi
    theo danh mục"; "Giữ lại N% tiền vào" meta on "Còn lại".
  - Icons: `arrowLeft` (ChevronLeft) registered beside `arrowRight`.
