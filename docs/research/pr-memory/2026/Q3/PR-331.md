## Independent review round 1 — 2026-08-09

**Evaluator provenance:** fresh-context ChatGPT review session, separate from the implementation conversation.

**Inputs reported reviewed:** `AGENTS.md`, `docs/plans/active/single-agent-delivery-system.md`, the actual PR #331 diff, and current exact-head CI evidence. The author summary was not treated as authority.

**Verdict:** `REQUEST CHANGES — NOT READY FOR REVIEW/MERGE`.

### Blocking findings

1. **Compound `Go` action:** G2 combined obtaining independent review with addressing findings.
2. **Independent-evaluation bypass:** placeholder detection accepted values such as `blocked — ...` and `pending — ...`; implementer/evaluator separation and overlap were not enforced.
3. **Global active-packet ambiguity:** policy incorrectly said one active packet globally instead of one execution packet per workstream/session.
4. **SECURITY DEFINER false-negative risk:** regex comment stripping could treat comment markers inside SQL literals as comments and hide executable SQL.

### Round-1 remediation

- introduced workstream-scoped `Packet role: execution|supporting` semantics;
- migrated Secure so Provider Sync/recent-auth are supporting and one Secure acceptance packet owns terse approvals;
- added gate task/action kind and basic compound-action checks;
- added implementer/evaluator/artifact/overlap fields and negative tests;
- replaced regex SQL stripping with a lexical state machine for comments, strings, identifiers and dollar-quoted bodies.

## Independent review round 2 — 2026-08-09

**Evaluator provenance:** fresh-context ChatGPT follow-up review supplied by owner, separate from the implementation conversation.

**Exact head reviewed:** `0b23778aa762e20ff5e926e36454d7d44aec0de2`.

**Verdict:** `REQUEST CHANGES — NOT READY TO MARK READY`.

### Resolved from round 1

- global active-packet ambiguity resolved;
- original G2 compound action resolved;
- independent-review identity model largely resolved;
- direction of replacing regex SQL stripping was accepted.

### Remaining blocking findings

1. **Mixed-case PostgreSQL dollar-tag false negative.** The scanner lowercased SQL before lexical sanitization even though PostgreSQL dollar-quote tags are case-sensitive. A `$TAG$ ... '$tag$' ... $TAG$` body could be lexed incorrectly and hide a later executable `SECURITY DEFINER` declaration.
2. **Independent-review sentinel bypass.** `none`, `n/a`, `not applicable`, `missing` and `unavailable` were not treated as unresolved evaluator/review-artifact values.
3. **Compound `Go` parser bypass.** Comma verb chaining such as `review PR #331, fix blockers` and indented continuation lines after `Next allowed action` could evade the compound-action check because the parser only read the first bullet line.

### Round-2 acceptance verdict

- AC1: pass at policy level.
- AC2: pass after workstream migration.
- AC3: pass.
- AC4: fail until gate parser/chaining bypass is closed.
- AC5: fail until sentinel and continuation/compound bypasses are closed.
- AC6: fail until mixed-case dollar-tag false negative is closed.
- AC7: pass.

## Round-2 remediation applied on branch

The remediation is bounded to the three remaining findings:

- PostgreSQL SECURITY DEFINER scanner now receives raw SQL, performs lexical sanitization with the original case intact, and only then lowercases executable SQL for keyword matching;
- added a mixed-case `$TAG$` / `$tag$` regression fixture proving a later real SECURITY DEFINER declaration remains visible;
- placeholder detection now rejects `none`, `n/a`, `not applicable`, `missing`, `unavailable` and `not available` in addition to the prior pending/blocked/todo/tbd/unknown values;
- added sentinel negative tests for evaluator and review artifact;
- decision gates now reject indented continuation lines entirely so a second action cannot hide outside the parsed bullet value;
- compound-action detection now also rejects comma/plus verb chaining, including `review PR #331, fix blockers`;
- added regression tests for comma chaining and continuation-line hiding.

These remediations are branch evidence only. A short independent round-3 review must inspect these three fixes before the PR is marked ready and full Class-3 CI is triggered.
