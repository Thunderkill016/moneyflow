# Completed work packets

Completed packets preserve implementation intent, decisions, evidence and production verification.

Use the filename format:

```text
YYYY-MM-DD-short-slug.md
```

A packet is complete only after the pull request is merged, the exact production deployment succeeds and the affected flow is verified. Historical packets are evidence, not automatically current product truth; current rules remain in `AGENTS.md`, `ARCHITECTURE.md` and `docs/product/PRINCIPLES.md`.
