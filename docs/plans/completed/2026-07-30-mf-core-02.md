# MF CORE-02 — Remove Withdrawn Spending Advice

**Status:** completed  
**Owner:** MoneyFlow  
**Issue/PR:** #154 / #155  
**Completed:** 2026-07-30

## Outcome

Removed unsupported daily-spending advice from the active finance core and dashboard orchestration while preserving factual ledger summaries and current visible dashboard values.

The dashboard summary now reports only four observable financial facts: `balance`, `income`, `expense` and `net`. Planning data remains available to budgets, commitments, goals and attention surfaces, but it is no longer combined with total assets to generate an unapproved spending recommendation.

## Repository reconnaissance

Before this change:

- `src/lib/finance.ts` exported `DAILY_ALLOWANCE` and `calculateDailySpendingGuide`.
- `calculateDashboardSummary` returned `safeToday`, `dailyAllowance`, `forecast` and `foodExpense`, although the dashboard presentation accepted only `balance`, `income`, `expense` and `net`.
- `MoneyFlowDashboard` computed partial budget remainder, commitment reserves and savings inputs solely for the retired outputs.
- Several tests still legitimized the withdrawn behavior even though production UI no longer consumed it.

`ARCHITECTURE.md` already states that withdrawn product behavior must not remain exported from active core modules and that total assets are not automatically a spending budget.

## Research

MoneyFlow already separates ledger facts from planning inputs. Budgets, commitments and goals remain useful in their own UI and attention surfaces, but combining incomplete planning data with total assets into a recommendation had no approved product contract.

The correct action was removal, not replacement with another heuristic. This keeps the ledger factual and leaves future spending guidance dependent on a researched, explicit planning contract.

## Specification

- `calculateDashboardSummary` returns exactly `balance`, `income`, `expense` and `net`.
- Demo and authenticated values for those four fields remain unchanged.
- Remove `DAILY_ALLOWANCE`, `calculateDailySpendingGuide` and advice-specific types/options.
- Remove dashboard computations that only supplied advice inputs.
- Preserve budget progress, category ranking, balance reconciliation, split-expense behavior and transfer neutrality.
- Add a regression contract preventing the retired advice tokens from returning to active finance/dashboard source.
