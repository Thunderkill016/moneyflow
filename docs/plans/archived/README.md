# Archived work packets

This directory preserves superseded, abandoned, candidate, or historically useful
work packets that are neither current execution state nor accepted completed work.

They are historical provenance only. They do not grant permission, select next work,
or override `AGENTS.md`, `docs/research/CURRENT_PROJECT_MEMORY.md`, the active-packet
registry, current code/tests, or explicit owner decisions.

Keep a packet here when moving it to `completed/` would falsely imply an accepted
merge/deployment/product outcome. Move an archived packet back to `active/` only in a
new, explicit owner-approved task with a refreshed packet and current acceptance
criteria; do not resume an old branch from historical prose.
