# Active work packets

Only deliberately started, non-trivial work belongs here.

Each file must be copied from `docs/templates/FEATURE_WORK_PACKET.md` and kept current enough that another agent can continue without relying on chat history.

Before opening a new packet, check that the work is not already represented by an active packet or pull request. After production verification, move the packet to `../completed/` and fill in the delivery record.
